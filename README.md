# 重组文件全面复核

用于 A 股并购重组申报文件的可追溯复核，覆盖算术与会计勾稽、跨文件与加期一致性、底稿穿透、问询回复逻辑、发行方案复算和 Word 批注交付。

## 使用

将整个仓库目录作为 `filing-comprehensive-review` skill 安装，保留 `SKILL.md`、`references/`、`assets/` 和 `scripts/` 的相对目录结构。任务范围与执行要求见 [SKILL.md](SKILL.md)。

## 最近更新

- 区分上市公司、标的公司与标的资产。
- 新增批注及修订作者统一为 Jasper AI。
- 明确募集配套资金金额与发行股份数量的计算基数及发行时点。
- 核查国资委实际控制人情形下承诺及说明的实际出具主体。
- 重复披露本身不作为问题，仍核查多处披露的一致性。

## 适用边界

不适用于 IPO、再融资申报文件或纯语言格式整理。脚本及模型命中先列为候选，须回原始载体核验。法规的现行有效性应在实际复核前确认。
