# 错误分类体系与批注标签（从历次 AI 及人工复核结果提炼）

> 来源：某 A 股重大资产重组项目 `加期/AI复核结果/历次AI及人工复核结果/`（29 个含批注文件、1,966 条批注、
> 15+ 位审阅人：券商质控、审计机构、标的公司、独立财务顾问、项目组等）+《逐字精读审查报告》。
> 用途：①统一问题定级与标签；②作为批注版【类型标签】的取值表；③作为检查清单的触发词。
> 文中项目与机构名称均为历史项目来源说明，仅作示例，不得当作当前任务事实。

## 一、批注标签（【…】）取值表

### 数据类（优先，直接指向硬伤）
| 标签 | 含义 | 典型触发 | 默认定级 |
|---|---|---|---|
| 【数据错误】 | 与底稿/审定数不符 | 单值抄录错误、漏负号、单位错误 | A |
| 【数据错误｜与定稿附注不符】 | 与最终审计附注冲突 | 以附注为准 | A |
| 【勾稽】 | 合计/占比/比率不成立 | 金额相加不等于合计 | B |
| 【表格串行】 | 表格列错位 | 合计行跨列、列错位 | A |
| 【严重错误】 | 逻辑不可能成立 | 持续＋终止≠净利润、子集大于全集 | A |
| 【跨文件数据不一致】 | 同一指标跨文件不同 | 报告书 vs 问询回复 | A |
| 【跨文件口径不一致】 | 口径/分母不同致金额比例不同 | 新增商誉含不含原有商誉 | B |
| 【与表格矛盾】 | 正文与同文表格冲突 | 正文占比与表内合计 | B |

| 【与XX题矛盾-需统一】 | 跨章节同一事实冲突 | 历史沿革年份、名称、金额 | B |

### 表述与逻辑类
| 标签 | 含义 | 默认定级 |
|---|---|---|
| 【表述风险】 | 确定性预测、绝对化表述（"将会""不存在""均"） | B |
| 【表述准确性】 | 表述与事实不符（如"年降产品涉及王朝系列"实际含海洋系列） | B |
| 【表述与内容不匹配】 | 引言与表体范围不符（说二十大实际不足） | C |
| 【逻辑错误】 | 归因错误、因果倒置、半年与全年不可比 | B |
| 【异常未解释】 | 数据异常变动未说明原因（立项数降52%未解释） | B |
| 【来源缺失】 | 引用数据/预测未注明来源 | B |
| 【方法探讨】 | 答复未回应监管提问的本意 | B |
| 【体例】 | 空标题、模板残留、编号层级不统一 | C |

### 证据与待办类
| 标签 | 含义 | 默认定级 |
|---|---|---|
| 【待补充】 | 结论缺支撑，需补数据/文件 | B |
| 【依据不足】 | 底稿无法支撑结论 | B |
| 【需核实】 | 存疑但无法定论，须回原始文件 | 不定级（按 CANDIDATE 处理） |

### 留痕类（批注版应同时保留正向痕迹）
| 标签 | 含义 | 默认定级 |
|---|---|---|
| 【勾稽-已复核无误】 | 已复算通过 | 不定级（正向留痕） |
| 【已直接修订】 | 已改正 | 不定级（正向留痕） |
| 【复核说明】 | 本轮修订口径说明 | 不定级（正向留痕） |
| 【肯定】 | 写法恰当、可保留 | 不定级（正向留痕） |

> 默认定级只是起点：最终以实际影响与证据状态为准。确认后影响披露准确性的 B 级应升 A（如勾稽差异确认为抄录错误）；升级或降级必须在 finding 的 `review_note` 中写明理由。

## 二、高频问题模式（按发生频次，来自 1,966 条批注的实证分布）

1. **数据/勾稽/金额不符**（最高频）：跨表合计、占比分母、单位折算、旧值残留；
2. **文字/错别字/漏字**：漏字（"合伙企业"漏"法"、"新能汽车"漏"源"、"中重型货市场"漏"车"）、叠词（"洞察到到""企业企业"）、重复项、错别字（"实物"→"实务"、"科技有限"→"有限公司"）、冗余（"综合税率所得税率"）；
3. **跨文件/跨章节不一致**：报告书 vs 问询回复 vs 底稿；同一事实在两题间打架；
4. **依据/证据不足**：结论无底稿支撑、引用数据未注明来源；
5. **口径/口径标注缺失**：多套口径并行且排序不统一；
6. **风险提示/审核问询预判**：站在监管视角预判追问点；
7. **逻辑/矛盾**：归因错误、方向颠倒、子集大于全集；
8. **格式/标点**：全角半角、括号体例（【】〔〕[]）、日期格式。

## 三、高价值新增检查项（本次复核未覆盖、应予补充）

| 检查项 | 做法 | 触发示例 |
|---|---|---|
| **会计恒等式** | 持续＋终止＝净利润；归母＋少数股东＝净利润；资产＝负债＋所有者权益；期末＝期初＋本期变动 | 持续经营净利润 > 净利润（本项目实证案例） |
| **跨章节同值异义** | 同一数字在不同章节是否被赋予不同含义 | 14.37% 在问题九为"三年平均"、在问题三/五为"2024 单年" |
| **多口径并存与排序** | 同一指标是否存在多套口径；排列顺序是否统一 | 三套毛利率；"2024在前/2025在前"混用 |
| **主体名称写法普查** | 提取全部企业全称，扫描子串变体（漏字、半角括号、语序） | 同一主体 4 种写法 |
| **跨载体一致性普查** | 同一主体/比例/金额在 正文段落／表格／图／表下注释／目录 五类载体间交叉比对；图形载体必须实际提取逐张识读 | 表已换版图未同步；图内漏股东致层合计<100%；图载旧名表载新名 |
| **出资表合计↔注册资本勾稽** | 出资/股权结构表"合计"与同节"基本情况表"注册资本（或出资总额）对碰，差额反查工商变更记录 | 合计 334,637.42 ≠ 注册资本 340,190.78，差额=一笔增资 |
| **标题与正文分子分母** | 标题表述与正文算式方向是否一致 | 标题"交易对价占业绩补偿"（实为补偿占对价） |
| **异常未解释** | 变动幅度较大却无原因说明 | 立项数 75→36 降 52%，结题 23→45 |
| **确定性预测表述** | 扫描"将会/必然/不存在/均"等绝对化词 | "产能利用率将会提升" |
| **答复方向匹配** | 监管问类型 vs 答复落脚点 | 问"风险"答"不存在风险" |
| **模板残留** | 空标题、编号层级 | "（一）""1、"下无内容 |
| **重要性重排** | 按"是否影响审核判断"重排优先级，而非按发现顺序 | 定性级矛盾优先于错别字 |

## 四、误报防治清单（先澄清、再定性）

| 易误报情形 | 处置 |
|---|---|
| 比率列被加总（成新率/完成率/占比） | 比率列不可加总；只验"分子÷分母"或"本行÷合计行" |
| 合并单元格造成"假错位" | 用 `build_logical_grid` 展开后再判 |
| 元/万元未折算 | 先判单位（比值≈10000 即为元口径）再比对 |
| 主体混淆（上市公司/标的公司/备考口径） | 先做主体识别（用 2025/2024 稳定列锚定），再比对 |
| 四舍五入尾差 | ≤0.05 万元或 ≤0.01 个百分点且可解释者，写入"尾差说明"而非错误清单 |
| 口径差异被误判为错误 | 见 `references/qa-logic-review.md` 第六节"看似矛盾、实为口径差异"表 |
| 负数分类导致"子集大于全集" | 查是否有红字冲回/退货/折让，要求加表注而非改数 |
| 半年数与全年数直接比较 | 需年化或注明不可比 |

## 五、证据状态（与影响等级分离）

影响等级 A/B/C 只表达问题影响，不表达证据是否已经确认。每条 finding 另加以下状态：

| 状态 | 使用条件 | 批注措辞 |
|---|---|---|
| `CONFIRMED` | 已回原始段落、表格、公式或权威来源确认 | "请改为……" |
| `CANDIDATE` | 脚本、模型、OCR 或模糊匹配命中，尚未确认 | "请核实……" |
| `PASS` | 指定检查已完成且未发现问题 | "已核对一致" |
| `UNVERIFIABLE` | 关键证据不可得或来源互相矛盾 | "本次无法核验，原因……" |
| `NOT_IN_SCOPE` | 明确不在本次范围 | "本次未纳入范围" |

禁止把 `CANDIDATE` 写成错误，禁止把 `UNVERIFIABLE` 写成通过，禁止把 `NOT_RUN` 写成零问题。A 级 `CONFIRMED` 问题必须至少有三项反证记录。

## 六、复核踩坑与硬约束

1. **表格合并与串行**：精确定位和验算必须使用原始 `w:tc` 的 gridSpan/vMerge 逻辑网格，不能直接相信 `row.cells` 的友好视图。
2. **修订痕迹统计**：用标签边界匹配 `w:ins`，避免 `w:insideH` 造成假阳性。
3. **接受修订后正文**：递归提取 `w:t`，包含 `w:ins`，排除 `w:del`；否则会漏掉插入文字。
4. **批量算术误报**：分类小计、两层合计、加减结构、列错位和合并单元格均可能造成假差异，必须回原始单元格确认。
5. **表号会漂移**：位置一律使用文件名简称、章节、小标题、表名和原文锚点，不用表号作为唯一定位。
6. **旧值残留**：同时检查旧值、新值、联动值、元/万元等价形式和所有关联文件。
7. **跨文件范围**：主文件组成部分也要检查，不得把它误称对照文件；同一指标出现三处以上必须全部两两对碰。
8. **中文改义词**：万/亿、增/减、应收/应付、毛利/净利、收入/收益、控股/参股等命中后优先人工复核。
9. **覆盖限制**：comparison_exclusions、arithmetic_skips、parse_errors 和降级事项必须结构化记录。
10. **独立复核**：独立 Agent 必须直接读取原始文件，不继承主 Agent 结论；若无法独立复核，必须显式披露。
