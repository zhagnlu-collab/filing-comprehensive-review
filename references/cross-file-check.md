## 1. 同一指标≥3处时三处两两对碰（gotcha #5）

同一指标在全文中出现≥3处时，不能只比碰到的两处，必须全部两两对碰。

```python
# 构建 (主体, 指标, 期间) → [(文件, 位置, 数值)] 索引
from collections import defaultdict
groups = defaultdict(list)
for r in all_facts:
    key = (r["subject"], r["metric"], r["period"])
    groups[key].append((r["file"], r["loc"], r["value"]))

for key, items in groups.items():
    if len(items) >= 2:
        vals = set(v for _, _, v in items)
        if len(vals) > 1:
            print("冲突: %s" % (key,))
            for f, loc, v in items:
                print("  %s %s = %s" % (f, loc, v))
```

**主体归属铁律**：每个数据点强制标注主体归属（如"东实李尔"vs"东实李尔（武汉）"vs"东风康明斯排放"），跨文件比对时先确认"比的是同一个主体"，避免张冠李戴式误报。

## 2. 方向词 vs 数据（gotcha #4）

对加期变动识别的段落，逐句检查"增长/下降/上升/减少/增加"等方向词与数据方向是否一致。上期"同比增长"的措辞可能照抄到本期但数据实为下降。

```python
import re
UP = ("增长", "上升", "增加", "提升", "提高", "上涨")
DOWN = ("下降", "减少", "降低", "下滑", "下跌")
NUM_PAIR = re.compile(r"从\s*(-?\d{1,3}(?:,\d{3})*(?:\.\d+)?)\s*(?:万元|亿元|%|元)?\s*(增至|增加至|增长至|下降至|降至|提升到|提高到)\s*(-?\d{1,3}(?:,\d{3})*(?:\.\d+)?)")

for m in NUM_PAIR.finditer(text):
    a, word, b = m.group(1).replace(",", ""), m.group(2), m.group(3).replace(",", "")
    va, vb = float(a), float(b)
    if any(w in word for w in ("增", "增长", "提升", "提高")) and vb < va:
        print("方向反转: %s" % m.group(0))
    if any(w in word for w in ("降", "下降", "减少")) and vb > va:
        print("方向反转: %s" % m.group(0))
```

## 6. 特征差额汇总与反查规则（借自问题十跨篇提示）

复核完成后，把所有"仅加期列有误"的差异归纳为若干**特征差额**，每个特征差额列出其出现的所有文件/章节位置，并给出可操作的**反查规则**。

### 方法

1. **收集所有"仅加期列有误"的差异**：历史各期一致、仅最新一期（如 2026H1 或 2026.6.30）不一致的差异；
2. **按差额分组**：把差额相同的差异归为一组，计算该差额出现的所有位置；
3. **验证同源**：若多个位置的差额完全相同（如 96.12 出现在货币资金/净利润/现金流量/财务费用四处），基本可判定为同一根因（同一批未同步的旧版数据）；
4. **输出《特征差额汇总表》**：列 = 特征差额 / 出现位置（文件+章节）/ 涉及指标 / 根因定性 / 反查规则。

### 示例（历史项目实测）

| 特征差额 | 出现位置 | 涉及指标 | 根因定性 | 反查规则 |
|---------|---------|---------|---------|---------|
| 96.12 万元 | 报告书第九章现金流量分析、【五】财务费用、【七】表55 货币资金与表46 净利润 | 收到其他与经营活动有关现金、财务费用、货币资金、净利润 | 同一批未同步的旧版数据 | 凡 2026 年 1-6 月数与审定数相差 96.12 的，基本可判定为同一批未同步数据 |
| 289.33 万元 | 【六】表6 利润总额、【九】表53 EBITDA 与利息保障倍数、【十】表9 归母净利润（组成部分） | 利润总额、EBITDA、利息保障倍数 | 旧版利润总额 | 凡涉及利润总额/EBITDA/利息保障倍数的，检查是否用旧版利润总额 22,193.00 计算 |
| 1.24 万元 | 【七】表47 递延所得税资产、【十】表9 归母净利润（组成部分） | 递延所得税资产、归母净利润 | 递延所得税资产差额 | 凡涉及递延所得税资产的，检查是否用旧版数 |
| 201.46 万元 | 【六】表4 权益法投资收益（表4 与表8 内部矛盾） | 权益法投资收益 | 权益法投资收益旧版 | 凡涉及权益法投资收益的，检查表4 与表8 是否一致 |
| 246.98 万元 | 【一】备考归母净利 1.39 亿、【二】13,893.61、【六】表7、【九】表85（组成部分） | 备考归母净利润 | 备考归母净利润旧版 | 凡涉及备考归母净利润的，检查是否用旧版数 13,893.61 |

### 反查规则的应用

- 发现一处差异后，按特征差额反查全文档：凡最新一期数与审定数相差该特征差额的，基本可判定为同一批未同步数据，可一并处理；
- 特征差额汇总表作为交付物的一部分，便于项目组按特征差额批量定位和处理，避免逐处单独排查。

## 7. 简称释义完整性复核（借自 document-support-verification B6）

若文件含"释义"章节（定义"简称→全称"）：

1. 提取释义表中所有简称及其对应全称；
2. 在正文搜索每个企业名称的首次出现，确认是否使用了释义表中的简称；
3. 正文使用了某简称但该简称不在释义表中 → 披露遗漏（B 级）；
4. 同一企业在不同章节使用了不同简称 → 披露不一致（B 级）；
5. 释义表中有简称但正文从未使用 → 冗余释义（C 级，备查）。

## 8. 母公司/单体报表前置校验（借自 document-support-verification）

判定"母公司口径/单体口径无法从文件独立复核"前，必须先检索文件中的母公司/单体资产负债表、利润表、现金流量表，抽取关键科目并计算验证。未完成前禁止输出"无法勾稽/未底稿复核"等负面结论。

## 9. 统一状态与证据引用

跨文件对碰结果必须挂接 claim/source/evidence，不允许只保留"通过/不通过"两个词：

- 每个数据点分配 `CLM-` ID；
- 每个来源分配 `SRC-` ID；
- 每个比对证据分配 `EVD-` ID；
- 每个异常 finding 分配 `FND-` ID；
- 找不到同口径对照时记录 `comparison_exclusion`；
- 来源或底稿不足时使用 `UNVERIFIABLE`，不得写成一致。

统一覆盖状态：

- `COMPLETE`：按要求完成全部适用对碰；
- `PARTIAL`：部分完成并列出缺项；
- `NOT_RUN`：未执行并说明原因；
- `UNVERIFIABLE`：关键证据不可得；
- `NOT_IN_SCOPE`：用户确认不在范围。

跨文件差异升级为 `CONFIRMED` 前必须确认主体、期间、单位、口径、币种和来源版本；仅数值不同不能自动定性。具体字段见 `evidence-ledger.md`。

## 10. 补充披露反向对碰（问询回复 ↔ 申报文件修订稿）

问询回复中的补充披露标注，必须与申报文件修订稿双向一致，缺任一方向即问题：

1. **提取承诺清单**：扫描回复中"已在报告书第 X 章补充披露""已修订……""详见……（修订稿）"等句式，以及全部楷体加粗（或项目约定体例）的补充披露段落，形成"补充披露承诺清单"（问题号 → 拟披露位置 → 内容摘要/数值）；
2. **逐条回查修订稿**：每条承诺回报告书修订稿对应章节核验——该章节是否确有该内容、数值与回复是否一致、标注体例是否同步；
3. **反向扫描**：修订稿中楷体加粗/修订的内容，是否都能在问询回复中找到对应出处；多出或缺失均须说明；
4. **判定**：回复承诺补充披露但修订稿未落实 = A 级（对监管承诺未兑现）；数值不一致按跨文件数据不一致处理；仅体例未同步 = C 级。

注意：补充披露体例依项目约定（楷体加粗/修订模式/无标注），以范围卡确认的 `markup_convention` 为准；无标注项目改用上期 diff 识别。
