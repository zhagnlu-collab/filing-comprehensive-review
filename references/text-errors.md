# 文字表述错误专项扫描

> 借自另一 AI 质检报告的文字/标点错误检查项。这些错误不影响数据准确性，但直接影响申报文件的专业度和交易所审核印象——交易所看到"和字连接""叠词""漏字"会直接质疑复核质量。属 C 级问题，但应逐项列出。

## 1. 和字连接（顿号+和字混用）

**规则**：并列列举 ≥3 项时，最后两项之间用"和"，前面用顿号"，"或逗号"，"——**不得全部用"和"**。

**错误示例**：`分别为 74.05%和75.27%和68.59%`
**正确写法**：`分别为 74.05%、75.27%和68.59%`

**检查方法**：
```python
import re
# 匹配 "X%和Y%和Z%" 或 "A和B和C"（≥2 个"和"且无顿号）
pat = re.compile(r"[\d\.]+%?\s*和\s*[\d\.]+%?\s*和\s*[\d\.]+%?")
# 更通用：连续两个"和"之间无顿号/逗号
pat2 = re.compile(r"和[^，、]*?和")
```

**注意**：重大事项提示章节若有正确写法，正文复制后未同步修改，属"复制未同步"——需在正文中标注"与重大事项提示同一处文字不一致"。

## 2. 叠词

**规则**：相邻两字重复且非合法叠词（如"研究研究""商量商量"）。

**错误示例**：`本次交易交易对方`（应为`本次交易的交易对方`）
**常见模式**：`的的`、`了了`、`和和`、`与与`、`及及`、`在在`、`为为`

**检查方法**：
```python
pat = re.compile(r"(.)\1(?=[的一是])|交易交易|报告报告|文件文件|数据数据")
```

## 3. 漏字

**规则**：固定搭配/专业术语中漏字，导致语义不完整。

**错误示例**：`评估方法与目的的相关性`（漏"评估"，应为`评估方法与评估目的的相关性`）
**常见模式**：
- `X与Y的相关性/匹配性/一致性` → 检查 X、Y 是否完整
- `评估方法与目的` → `评估方法与评估目的`
- `审计与会计` → `审计与会计准则`

**检查方法**：对固定搭配建立词表，扫描缺失变体。

## 4. 自指（首项与总项同名）

**规则**：列举式表述中，总项与首项同名，可读为"包括自身"。

**错误示例**：`湖北唐钢汽车板有限公司包括湖北唐钢汽车板有限公司、东时（武汉）新能源科技有限公司`
**正确写法**：`湖北唐钢汽车板有限公司包括其本部及东时（武汉）新能源科技有限公司` 或 `湖北唐钢汽车板有限公司（含东时（武汉）新能源科技有限公司）`

**检查方法**：
```python
# 匹配 "X包括X"（X 为企业全称或长名词）
pat = re.compile(r"([\u4e00-\u9fa5]{4,}有限公司)包括\1")
```

**延伸**：自指还可能涉及"同一控制关系归集逻辑"问题（如东时（武汉）新能源与湖北唐钢是否确属同一控制），建议核实归集逻辑是否成立，必要时附工商股权结构佐证。

## 5. 文号括号混用

**规则**：文号年份应统一用六角括号 `〔〕`（规范写法），不得混用方头括号 `【】` 或方括号 `[]`。

**错误示例**：`东洲评报字【2025】第2840号`、`（十）应急罚【2025】执法19号`
**正确写法**：`东洲评报字〔2025〕第2840号`

**检查方法**：
```python
# 扫描方头括号文号
pat = re.compile(r"【\s*20\d{2}\s*】")
# 扫描方括号文号
pat2 = re.compile(r"\[\s*20\d{2}\s*\]")
```

**判定**：全文统计三种括号的出现次数，若混用且非统一格式，提示统一为 `〔2025〕`。

## 6. 高频易混词

| 易混词 | 正确 | 检查方法 |
|--------|------|---------|
| 其它 / 其他 | 统一为"其他" | 扫描"其它"出现次数，>0 即提示 |
| 截至 / 截止 | "截至"通用；"截止"仅用于"截止性测试"等 | 扫描"截止"出现位置，非专业术语处提示 |
| 制定 / 制订 | "制定"通用 | 扫描"制订"出现位置 |
| 体现 / 反应 | "体现"通用 | 扫描"反应"在"反应情况/反应问题"等搭配中 |
| 必须 / 必需 | "必须"（副词）/"必需"（形容词） | 扫描"必需"在副词位置 |

## 7. 半角/全角标点

**规则**：中文句中应使用全角标点（，。；：？！""''（）），半角标点仅用于数字千分位（1,501.7）、小数点（3.14）、英文缩写（Co., Ltd.）、网址、代码。

**错误示例**：`2026年以来,我国汽车市场短期承压`（半角逗号）
**检查方法**：
```python
# 中文上下文中的半角逗号/句号
pat = re.compile(r"[\u4e00-\u9fa5][,\.]|[,\.][\u4e00-\u9fa5]")
# 排除数字千分位和小数点
def is_valid(s):
    return bool(re.search(r"\d[,\.]\d", s))
```

## 8. 主体简称与指代

**规则**：“公司”通常指“上市公司”，注意不要将标的公司简称为“公司”。标的公司使用文件释义中已定义的简称或“标的公司”。

**检查方法**：结合释义、句子上下文和所述业务/财务数据核查“公司”的实际指代；指代标的公司的，提示改为对应简称或“标的公司”。法规原文及直接引文逐字保留，不机械替换；指代不明确时列为候选并请核实。

## 9. 标的公司与标的资产

**规则**：区分“标的公司”和“标的资产”。“标的公司”指公司主体；“标的资产”应指代标的公司的股权，而不是指代标的公司。具体股权范围以本次交易方案和文件释义为准。

**检查方法**：结合释义、交易方案和上下文，核查两者是否混用。涉及公司主体的经营、财务、人员等表述，使用“标的公司”或其已定义简称；涉及本次交易购买的股权，使用“标的资产”。不得自行补充股权比例；法规原文及直接引文逐字保留，不机械替换，指代不明确时列为候选并请核实。

## 10. 国资委实际控制人情形下的承诺与说明主体

**规则**：如果上市公司的实际控制人是国资委，那么重组报告书中通常不应该出现“上市公司实际控制人承诺：……”的类似字眼，因为国资委通常不会出具承诺或说明文件。

**检查方法**：
- 先结合报告书实际控制人披露、股权结构及文件释义确认本项是否适用；适用时，检查正文及承诺汇总表中“上市公司实际控制人承诺”“控股股东及实际控制人承诺”“实际控制人出具说明”等类似表述。
- 对照承诺函、说明文件的原始签章页，核对实际出具主体、文件内容及披露范围；不得将控股股东、国有股东或其他主体出具的文件归属于国资委，也不得在无依据时直接改成“控股股东承诺”。
- 保留“通常”的限定：若确有国资委出具的原始文件，按文件如实披露；不能仅因实际控制人为国资委就认定错误。缺少原始文件或主体不明时列为 `CANDIDATE`，提示核实出具主体及文件依据；经原始文件确认归属错误后，再按证据状态规则升级为 `CONFIRMED`。
- 修订建议以已核实的实际出具主体和文件内容为准，同步检查承诺汇总表及其他章节中的同类表述；法规原文及直接引文逐字保留。

## 11. 引用错误与参见错误

**规则**：内部引用必须同时满足目标存在、定位准确及内容相符。不能仅因全文出现同名标题或关键词就认定“参见”“详见”有效。

**错误类型**：
- **目标不存在**：被参见的章节或小节在当前文件中不存在。
- **编号或名称错误**：目标内容存在，但引用的编号、标题名称或上级章节路径与正文不一致；同名小节位于其他章节也不能视为定位正确。
- **目标内容不符**：标题存在且定位无误，但其正文没有可参见的相关内容，或未涵盖引用句所指的具体事项。

**检查方法**：
1. 全文提取“参见”“详见”“具体见”“相关内容见”等指向章节、小节、表格、附注或其他文件的引用，保留完整引用句和路径。
2. 以当前正文建立标题层级索引，逐层核对上级章节、编号和标题名称；目录只作辅助，还须与正文核对。模糊匹配或相近标题仅用于寻找候选，不能替代核验。
3. 实际读取目标小节从标题到下一同级或更高级标题之间的内容，结合引用句判断其是否提供所指事项；不能用目标章节之外的内容、标题字面一致或一般关键词命中代替。目标仅再次参见其他位置的，继续追踪至实质内容，记录断链或循环引用。
4. 文档改版、章节增删或编号调整后，回查所有受影响的引用；引用其他文件的，核对明确文件名、适用版本及对应位置。引用页码、书签或自动交叉引用域的，检查实际落点和显示结果，不能只核查域代码存在。
5. 发现错误时，分别记录引用句原文、被引路径、实际目标标题及相关内容，说明属于不存在、定位错误还是内容不符。建议改到已经核实的正确位置；没有可核实的承接内容时提示补充披露或调整引用，不自行编造目标标题。

**示例**：披露参见“重大事项提示”之“七、本次交易对中小投资者权益保护的安排”，须核对“重大事项提示”下是否确有该编号及名称的小节，并确认小节内容确实承接引用句所指事项。该小节不存在、名称不同或虽存在但没有相关内容，分别按上述类型记录。

**判定边界**：先按证据状态规则确认；无法读取目标文件或内容时记录证据缺口，不直接认定目标不存在。问题影响等级按实际后果判断，不能把导致关键披露无法定位或实质缺失的问题一律降为文字提示。此项不以合理的重复披露为错误，也不改写法规原文及直接引文。

## 12. 扫描执行建议

1. **先扫全文正则，再人工复核**：正则命中后，逐项回原文确认是否为误报（如"和和"可能是"和和美美"合法叠词）；
2. **按章节统计**：文字错误按章节分布统计，便于项目组分章节修订；
3. **与数据错误区分**：文字错误单独成区（C 级），不与数据错误（A/B 级）混杂；
4. **复制未同步标注**：若同一表述在不同章节正确/错误并存，标注"与 XX 章节同一处文字不一致（复制后未同步修改）"。
